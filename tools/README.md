# 工具目录说明

## novel_to_corpus.py —— 小说 → 陪聊风格语料加工

**用途**：把你提供的小说文本抽成对白草稿，供人工改写为共情对话语料。这是"喂小说训练"的正确入口——小说不能直接训练，必须加工。

### 使用步骤

1. **放小说文件**：把 `.txt` 小说放到 `data/novels/`（支持 UTF-8 / GB18030 / UTF-16）。
2. **运行加工**：
   ```bash
   python tools/novel_to_corpus.py
   # 或指定单个文件
   python tools/novel_to_corpus.py --input "data/novels/某本小说.txt"
   ```
3. **看报告**：`data/corpus/novel_report.txt` — 重点看【安全告警清单】，命中的对白要人工剔除。
4. **人工改写**：`data/corpus/novel_style_draft.jsonl` 里每条 assistant 是"待改写"骨架，需要人工改成"接住情绪 + 温和追问"的共情回应。
5. **入训练集**：审核后的语料按场景抽样（**小说风格语料占比 ≤20%**），与 `03_sft_trainset.jsonl` 合并，跑 `06_regression_check.py` 门禁。

### 三条铁律（写死在脚本设计里）

- **不自动混入训练集**：产出全部标 `status=needs_review`，没有任何一步会把它直接加进训练数据。
- **安全预警必看**：恋爱依赖 / 自伤细节 / 医疗承诺 / 暴力 / 未成年人相关对白全部打标，人工剔除后才可用。
- **危机话术不生成**：危机场景的 assistant 骨架明确写"由系统硬兜底"，小说里任何相关对白都不进训练——避免模型学到错误转介方式。

### 为什么小说语料只能当"风格补充"

小说对白是"角色对角色"、服务于剧情冲突，跟陪聊需要的"用户对助手、接住情绪"结构不同。它能教模型自然中文的语气和节奏，但提供不了正确的共情回应范式，更没有安全边界。所以：主数据必须是人工写的共情对话（01 文档样例是种子），小说语料只占少量用来增加语言多样性。
