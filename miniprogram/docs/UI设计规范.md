# 情感陪聊小程序「许清楚」UI 设计规范

> 版本 v0.1 ｜ 阶段：纯 UI 壳子（完整聊天界面 + 模拟回复，不接真实模型）｜ 主基调：浅色主题
> 设计基准：**750rpx**（逻辑宽 375pt，1px = 2rpx）。所有尺寸默认 rpx，需 px 时按 1px=2rpx 换算。
> 唯一视觉依据：本文档 + 分层 Design Token。设计与开发同源，禁止在组件内硬编码色值／尺寸。

---

## 1. 设计定位与情绪基调

### 1.1 一句话定位
"随时可说、被认真听见"的对话页——界面形态对标豆包／元宝等主流 AI 聊天助手（单聊天页 + 消息流 + 底部输入 + 快捷开场），让用户零学习成本进入。

### 1.2 情绪基调三关键词
| 关键词 | 视觉落点 | 为什么这样定 |
|---|---|---|
| **陪伴感** | 暖色系（珊瑚/奶油白）、圆润大圆角、助手有名字"许清楚"+头像+在线状态、文案式提示 | 目标用户 18–35 岁独居/异地、深夜受挫场景，需要"有人在"的实感；冷冰冰的工具感会放大孤独。 |
| **温暖** | 暖白背景（#FBF9F7）而非纯白，暖灰文字，暖珊瑚主色，柔和阴影 | 情绪脆弱用户对"医院白+临床蓝"高度敏感，医疗冷感直接触发防御心理，且与"陪伴非治疗"定位冲突。 |
| **克制** | 单一主色、留白充足、无拟人情恋人暗示、无炫动效、无夸张表情包 | 红线明确禁止"虚拟恋人式依赖养成"。过度甜腻/拟人化会诱导依赖、替代现实关系，属合规红线，视觉上必须收敛。 |

### 1.3 与红线的视觉对应（硬性）
- **不出现**：白大褂/听诊器/十字医疗符号、蓝紫临床渐变、心跳监护波形、 Hot 粉红恋人配色、"已治愈"类承诺视觉。
- **不出现**：红色警报式危机弹窗（闪烁、感叹号警笛、纯红满屏）——危机态走温暖醒目路线（见 4.7）。
- **必须出现**：首屏/关于页的"AI 陪伴工具·非医疗"免责声明（24rpx，弱化处理但可读）；危机态的热线卡片与"人工跟进中"标识。

### 1.4 入口一致性
沿用主流聊天智能体信息架构：**顶部标题栏 → 中部消息流 → 底部输入条**，本期不设 TabBar（纯壳子阶段聚焦单页对话），右上角系统胶囊按钮区域保持原生、不做任何自定义覆盖。

---

## 2. 设计基准与安全区

- 设计稿宽 **750rpx**；字号/间距/圆角一律 rpx，禁止硬编码 px。
- **状态栏**：使用微信原生，`env(safe-area-inset-top)` 预留，不自绘。
- **顶部导航**：自定义导航内容高度 **88rpx**（不含状态栏）；右上角预留胶囊避让区 **宽 220rpx × 高 88rpx**，任何可点元素不得侵入。
- **底部输入区**：`padding-bottom: env(safe-area-inset-bottom)` 预留全面屏 Home Indicator 区（约 68rpx）。
- **字体**：系统字体栈 `-apple-system, "PingFang SC", "Helvetica Neue", sans-serif`；不引入外部字体（包体积与加载性能约束）。

## 4. 聊天页逐区规范

### 4.1 顶部导航栏
- 高度 **88rpx**（状态栏以下），背景 `#FFFFFF`，底部 `1rpx #EBE5DF` 描边。
- **左侧**：助手头像（56rpx 圆，见 5） + 标题"许清楚"（32rpx / 600 / `#2A241F`），下方一行状态"● 在线陪伴中"（24rpx / `#7D736A`，圆点 `#3E9C7A` 8rpx）。
- **右侧**：系统胶囊原生保留，**禁止**在右 220rpx 内放任何元素。
- 无返回箭头（单页壳子）；若后续接入二级页，返回图标 44rpx 置于最左。

### 4.2 消息列表
- 容器：页面左右 padding **24rpx**，上下独立于导航/输入区，`padding: 24rpx 0 24rpx`。
- **时间戳**：居中，24rpx / `#7D736A`，上下 `space-3`，格式"今天 22:14"；按会话日期分组，非每条都显示。
- **助手消息（左）**：头像（64rpx 圆）在左，`margin-right: 16rpx`；头像上方无名称时，气泡上方显示"许清楚"（24rpx / `#7D736A`，左对齐）；气泡 `max-width: 70%`（≈525rpx），`padding: 20rpx 28rpx`，字号 28rpx/行高1.6。
- **用户消息（右）**：气泡靠右，`max-width: 70%`，无名称/头像可选（建议显示极简"我"头像 64rpx 于右侧以对齐沉浸感，色 `#D9D1C9`），气泡底 `#F7E6DF`；尾部尖角朝右下。
- 消息间距 **24rpx**；长文本换行不截断，超长连续字符 `word-break: break-all`。
- 免责声明：会话顶部一条弱提示（24rpx / `#7D736A`，浅底 `#F5F1ED`，圆角 12rpx，左右 24rpx padding），文案："本产品为 AI 陪伴工具，非医疗机构或心理咨询服务，不能诊断、治疗疾病。如有紧急困扰请拨打热线 12356。"（仅首屏展示一次）。
- 列表滚动：新消息 `scroll-into-view` 定位到底部；滚动动画 200ms。

### 4.3 输入区
- 固定底部，背景 `#FFFFFF`，顶部 `1rpx #EBE5DF` + `shadow-md`（向上），`padding: 16rpx 24rpx`，`padding-bottom: calc(16rpx + env(safe-area-inset-bottom))`。
- **快捷提示行**（无输入或空态时常驻，输入中隐藏）：横向 `scroll-view`，chip 高 64rpx（点击热区补足至 88rpx）、`padding: 0 28rpx`、底 `#F5F1ED`、描边 `1rpx #EBE5DF`、圆角 pill、文字 24rpx / `#7D736A`；chip 间距 16rpx。预置："今天有点累" / "想找人聊聊" / "谢谢你在"。
- **输入框**：`flex:1`，底 `#F5F1ED`，圆角 20rpx，`min-height: 88rpx`（单行），`max-height: 200rpx`（多行滚动），`padding: 20rpx 24rpx`，字号 28rpx；占位符"说点什么，我在这儿…"（`#A89E94`）。
- **发送按钮**：88rpx 圆形，底 `#B85A3F`，白色发送图标（CSS 三角/➤，禁用纯图片），右侧 `margin-left: 16rpx`；有内容时启用，无内容禁用（`#D9D1C9`）。
- 发送动效：按钮 `scale(0.96)` 100ms；消息入场 `transform: translateY(8rpx)`+`opacity` 200ms（走合成层）。

### 4.4 空态（Empty）
- 居中展示，垂直分布于消息区中段：
  - 插画/标识：CSS 或 emoji（🌿/💬），96rpx，位于顶部。
  - 主标题"嗨，我是许清楚"（40rpx / 600 / `#2A241F`）。
  - 副标题"随时可以说，我会认真听你说"（28rpx / `#7D736A`）。
  - 免责声明小字（24rpx / `#7D736A`，两行居中）。
  - 下方紧跟 4.3 的快捷提示 chip（换行排布，居中）。
- 元素间距 `space-6`（48rpx）；无按钮主 CTA，靠 chip 引导开口（降低表达门槛）。

### 4.5 加载 / 打字中态（Typing）
- 助手侧：头像 + 气泡（同 4.2 位置），气泡内三点跳动指示器：3 个 12rpx 圆点 `#A89E94`，`opacity/transform` 循环动画（0.6s/点，错峰 0.2s），气泡宽约 88rpx、高 72rpx。
- 可选文字"许清楚正在想…"（24rpx / `#7D736A`）置于气泡下方，打字中态最大持续 8s，超时转 4.6 错误态。
- 动画仅用 `transform/opacity`，禁止逐帧改宽高。

### 4.6 错误态（模拟回复失败）
- 以助手侧气泡呈现，不弹窗、不红色满屏：文案"刚才没连上，我再听一遍就好"（28rpx / `#C0453B` 文字，气泡底 `#FFFFFF` + `1rpx #F0D9D5` 描边）；下方文字按钮"重试"（28rpx / `#B85A3F`）。
- 点击重试：气泡切换为 4.5 打字中态，2s 后回模拟回复。
-  crisis 场景的兜底失败**不得**只用此轻错误态——必须保证热线卡片始终可见（见 4.7）。

### 4.7 危机提示态 · 转介卡片（重点，视觉醒目但不惊吓）

**设计原则**：用"温暖 + 醒目"替代"警报 + 惊吓"。禁止纯红警示、闪烁动画、感叹号警笛图形；通过**暖色差异底、加粗描边、左侧强调条、关怀图标、加粗标题、大号热线号码**建立视觉优先级——在白色消息流中一眼可见，但情绪上传递"被关心"而非"被审判/出事"。

**规格**（作为助手消息插入，紧随危机触发的用户消息之后）：
- 容器：`max-width: 86%`（≈645rpx，比普通气泡宽以凸显），`background: #FFF7F2`，`border: 2rpx solid #ECC3B2`，`border-radius: 28rpx`，`padding: 28rpx 32rpx`，左侧 `8rpx` 宽强调条 `#C96A4F`（圆角同容器，可通过 `border-left` 或伪元素实现）。
- 标题行：emoji 关怀图标（🫂 或 💛，40rpx）+ 加粗标题"我想认真帮你一下"（32rpx / 600 / `#8A3B27`），与图标间距 16rpx。
- 正文：28rpx / 行高1.6 / `#4A3B33`，两到三句关怀话术（复用定位文档话术语气：不评判、给具体热线、已启动人工跟进）。
- **热线按钮组**（纵向排列，间距 16rpx）：
  - 首选号码（12356 全国心理援助热线）：chip 高 **88rpx**，`background: #FFFFFF`，`border: 2rpx solid #E3A78F`，圆角 20rpx，左 📞（32rpx），文字"拨打 12356" 32rpx / 600 / `#A8482F`，右侧小字"24小时 · 全国统一"（24rpx / `#7D736A`）。
  - 备选号码（400-161-9995 希望24 / 010-82951332 北京）：同款 chip 但高 72rpx、文字 28rpx、描边 `1rpx #EBE5DF`、文字 `#7D736A`。
  - 紧急行："若已受伤或控制不住，立刻拨打 120 / 110"，28rpx / `#5A5149`，左 ⚠（24rpx，静态不闪）。

## 6. 无障碍与适老化（a11y）

- **对比度**：正文 `#2A241F` on `#FBF9F7` ≈ 14:1 ✅；次级 `#7D736A` on `#FFF` ≈ 4.6:1 ✅；按钮白字 on `#B85A3F` ≈ 4.6:1 ✅。全部达 WCAG AA（正文 ≥4.5:1，大字 ≥3:1）。占位符 `#A89E94` 仅用于非关键信息。
- **字号下限 24rpx**，正文 28rpx；不得用 `< 24rpx` 承载有效信息。
- **点击热区 ≥ 88rpx**：发送按钮实体 88rpx；快捷 chip 视觉 64rpx 但 padding/命中区补足至 88rpx；热线 chip 主号实体 88rpx。
- **适老化模式**（预留开关，跟随系统字体缩放）：基础字号整体升一档（正文 28→32rpx、时间戳 24→28rpx、行高 1.6→1.7），气泡 `max-width` 调至 78%，chip 高升至 88rpx；提供"关怀大字版"入口时切换全局 Token 覆盖而非逐页改样式。
- **多通道编码**：在线状态=绿点+"在线陪伴中"文字；危机卡=图标+加粗标题+大号号码，均不依赖单一颜色。
- **读屏**：头像/图标加 `aria-label`（助手头像"许清楚"、发送"发送"、电话"拨打热线12356"）；消息气泡语义为文本，避免图片化文字。
- **动效克制**：尊重系统"减弱动态效果"——若开启，打字圆点与消息入场动画改为静态呈现（保留文字提示）。

## 7. 切图标注说明（零图片依赖优先）

**原则：本期 MVP 目标 0 张图片资源，全部用 WXSS + emoji + 文字 + CSS 形状实现，减小包体积（主包 <2MB）并规避多倍图维护成本。**

| 元素 | 实现方式 | 说明 |
|---|---|---|
| 助手/用户头像 | CSS 圆形 + 文字（"许"/"我"）或 emoji 🌿 | 免切图；如需品牌感可用纯 CSS 渐变圆 |
| 发送图标 | CSS 三角形（`border` 技巧）或 emoji ➤/⬆ | 线性风格，禁用位图 |
| 电话/关怀/警告图标 | emoji 📞 / 🫂 / ⚠ | 系统字体渲染，跨端一致 |
| 打字圆点 | 3 个 `view` 圆 + CSS animation | 纯 CSS |
| 危机卡强调条 | `border-left: 8rpx` 或 `::before` 伪元素 | WXSS 支持 |
| 免责声明底/气泡尾巴 | `background` + `border-radius` 差异角 | 纯 CSS |
| 空态插画 | emoji 🌿/💬（96rpx）+ 文字 | 免插画切图 |

**需图片资源的情形（本期均为可选，不实现）**：仅当后续要做品牌 IP 形象或节日主题插画时，按 @2x/@3x PNG 或 SVG 导出，同时提供暗色版或降亮遮罩；届时在此表补充命名规范（如 `icon_<name>@2x.png`）。

**标注口径**：设计稿标注写明 尺寸(rpx)/色值(HEX)/字号(rpx)/圆角(rpx)/间距(rpx)；开发按 1px=2rpx 换算，以 Design Token 为唯一来源。

## 8. 与工程开发的对接约定

### 8.1 Token 在 WXSS 的落地方式
- 在 `miniprogram/styles/variable.wxss` 用 CSS 变量集中声明 Semantic 层，页面/组件只引用变量：
  ```css
  page {
    --xc-bg-page: #FBF9F7;
    --xc-bg-surface: #FFFFFF;
    --xc-bg-subtle: #F5F1ED;
    --xc-brand: #D16B4C;
    --xc-brand-strong: #B85A3F;
    --xc-brand-press: #96482F;
    --xc-text-primary: #2A241F;
    --xc-text-secondary: #7D736A;
    --xc-text-placeholder: #A89E94;
    --xc-text-on-brand: #FFFFFF;
    --xc-border: #EBE5DF;
    --xc-bubble-user-bg: #F7E6DF;
    --xc-bubble-user-text: #3D3630;
    --xc-bubble-bot-bg: #FFFFFF;
    --xc-bubble-bot-text: #2A241F;
    --xc-crisis-bg: #FFF7F2;
    --xc-crisis-border: #ECC3B2;
    --xc-crisis-accent: #C96A4F;
    --xc-crisis-text: #8A3B27;
  }
  ```
- 组件示例写法：`background: var(--xc-brand-strong); color: var(--xc-text-on-brand);`。
- 允许固定值兜底（如单一圆角 `20rpx` 可直接写），但**色值一律走变量**，便于换肤/暗黑一键覆盖。
- 字阶/间距/圆角可在同一文件以变量声明（`--xc-fs-base: 28rpx` 等），或按团队约定直接写字面值，二者选一，全项目统一。

### 8.2 还原度验收（量化）
| 维度 | 验收方法 | 偏差阈值 |
|---|---|---|
| 色值 | 取色器比对，HEX 一致 | 完全一致（ΔE ≤ 2） |
| 尺寸/间距/圆角 | 标注 vs 真机测量（rpx） | ≤ 2rpx |
| 字号/行高 | 标注 vs 真机 | 字号一致，行高 ≤ 4rpx |
| 层级/阴影 | 截图叠加对比 | 无遮挡、无错位 |
| 关键态 | 空/加载/错误/危机态逐一切图走查 | 危机卡规格逐项核对 |
| 触控区 | 真机点测 | 所有主操作 ≥ 88rpx |

- 流程：开发自测 → UI 设计师走查（真机 + 设计稿叠加）→ 超限项返工。危机转介卡片为**必过项**，任何偏差须修正后方可进入下一阶段。
- 动态验收：微交互 100–300ms、转场 200–400ms；导出逐帧确认无重排抖动（用 `transform/opacity`）。
- 上线后结合埋点（开口率、快捷 chip 点击率、危机卡热线点击率）与 A/B 实验迭代视觉。
